- Two roles: **admin** (everything) and **entry** (add trips; see only own; no edit/delete).

## Decisions & why
- The supplied Kaaba artwork is stored as a local PNG with a white background and rendered as an image in the Arabic app header.
- **Supabase over Firebase:** relational data + Row Level Security enforces roles in the DB (not just UI).
- **Plain static web first, then Expo:** owner had no tooling; web was fastest to ship. Business logic in `src/lib/stats.ts` is a direct port of the web version, so behaviour should match.
- **No navigation library yet:** tabs are plain state in `App.tsx`. Move to Expo Router when screens grow.
- **Worker/trip numbers:** `trip_no` comes from a Postgres sequence (`R-000001`...), generated by the DB default, never by the client.
- **Officials/services are deactivated, not deleted**, so historic trips keep their names (FK is `restrict`).
- **User creation** uses the admin-only Edge Function because Supabase Auth user creation requires a service-role credential; that credential stays server-side. Role promotion remains available to admins in Settings under profile RLS.
- **In-app account creation:** the admin Settings screen invokes `supabase/functions/admin-create-user`; the Edge Function verifies the caller's JWT and admin profile before using the server-side service-role secret to create an email-confirmed entry user.
- **In-app account deletion:** Settings invokes `supabase/functions/admin-delete-user`; it verifies admin access server-side, prevents deleting the current or only admin, and blocks deletion when trips reference that user so historical ownership remains intact.
- The user deletion button displays an Arabic loading label and inline spinner while its request is in progress.
- The Settings users list uses the Log screen's card row pattern, with role as muted detail and horizontal promotion/demotion and destructive delete actions.
- The Settings screen lets admins rename officials inline; the existing officials update RLS policy enforces admin-only writes, so no Edge Function or service-role key is involved.
